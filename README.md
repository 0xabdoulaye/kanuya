# Kanuya

Site vitrine de **Kanuya**, l'application de rencontre 100 % guinéenne, pour
les relations sérieuses.

*Kanuya* : « l'amour, l'affection » en maninka.

## Ce dépôt

Public, et il ne contient **que le site**. Le code de l'application, backend
comme mobile, vit dans un dépôt privé séparé.

```
index.html                 la page
confidentialite.html       politique de confidentialité
conditions.html            conditions d'utilisation
assets/                    images, polices locales s'il y en a
```

## Mise en ligne

GitHub Pages, branche `main`, racine du dépôt. HTTPS fourni.

L'adresse publique sert aussi de **politique de confidentialité déclarée sur
Google Play**, qui exige une URL en HTTPS accessible sans compte.
